# freeCodeCamp Daily Challenges

Daily coding challenge solutions from freeCodeCamp, solved in Python.

Each folder contains one challenge, with the problem description, solution, and tests included in a single file.

## Structure

Each `day-XX-challenge-name/` folder contains a `solution.py` file with:
- A docstring describing the challenge, source, and date
- The solution function
- A set of tests using `assert`
